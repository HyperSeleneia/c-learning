# C 语言学习工作区

> 环境：Windows 11 + Visual Studio Community 2026 自带的 MSVC 编译器（已确认可编译运行）
> 工作目录：`E:\IC\c-learning`（本目录就是一个 Git 仓库，会同步到 GitHub）

## 目录结构

```
c-learning\
├─ build.cmd          # 命令行编译 + 运行（VS 出问题时的备用方案）
├─ notes.md           # 长期笔记：环境、约定、踩坑记录
├─ README.md          # 本文件
├─ daily\             # 每天的记录，一天一个文件：2026-10-24.md
│  └─ 2026-10-24.md
└─ lesson01\
   └─ hello.c         # 第一课：Hello World
```

新的一课建一个文件夹 `lesson02`、`lesson03`……，一天至少一个 `.c` 文件 + 一个 `daily` 记录。

## 每天的流程

1. 学完一集课，在对应 `lessonNN\` 里敲代码，跑通。
2. 在 `daily\` 下新建当天的 `YYYY-MM-DD.md`，按模板填 4 项（学了什么 / 代码在哪 / 卡住的地方 / 自评）。
3. 提交并推送（VS2026 右侧「Git 更改」→ 写提交说明 → 提交 → 推送）。

提交说明统一格式，方便以后追溯和让我复盘：

```
2026-10-24: 第1课 Hello World + 变量与 printf
```

## 怎么编译运行

在 VS2026 里：`Ctrl+F5`（开始执行不调试）。

命令行备用方案：在 `E:\IC\c-learning` 目录里运行

```
.\build.cmd lesson01\hello
```

成功时会看到：

```
hello.c

[OK] Running:
Hello, C!
```

编译失败时只做一件事：**从第一条 error 开始读**。后面的报错大多是第一条引起的连带错误。

## 学习路线（跟着凯哥的课走，这里只记里程碑）

| 阶段 | 内容 |
|------|------|
| 第 1 周 | 程序结构、`printf`/`scanf`、变量与数据类型、运算符 |
| 第 2 周 | 分支 `if/switch`、循环 `for/while`、嵌套与 `break/continue` |
| 第 3 周 | 函数、数组、字符串、作用域 |
| 第 4 周 | 指针、结构体、文件读写，做一个小项目（如通讯录/成绩管理） |

## 约定

- 变量名用英文小写加下划线，`main` 里写清楚每一步在做什么。
- 每段代码都要自己敲一遍，不要复制粘贴——手敲才会遇到报错，报错才是学习发生的地方。
- 卡住超过 15 分钟就问，问的时候贴：完整代码 + 完整报错原文。
